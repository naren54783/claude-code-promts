## 7. API Integration

## 9. Accessibility
Improve accessibility: semantic HTML, keyboard navigation, and focus states.

## 10. Testing
Add tests using Jest and React Testing Library for key components and flows.

## 11. Production Readiness
Prepare for production: env setup, error boundaries, build optimization.
